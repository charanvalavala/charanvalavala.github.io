# Applied AI portfolio site

A static, responsive portfolio for Charan Teja Valavala. It presents four
independent projects across retrieval, research tooling, evaluation, and
workflow design. BITS Hyderabad context appears in one project only. Evaluation
metrics are scoped to their labeled sets and documented limitations.

Open `index.html` in a browser to view the page. The Google Fonts link is a
progressive visual enhancement; system-font fallbacks remain available offline.
The two browser projects use GitHub Pages demo links. The RAGFlow card states
that live metrics require a configured indexed corpus. No personal contact
details are published.
